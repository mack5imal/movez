1Full-break overlay · five concepts, four states each (full instruction · collapsed instruction · /side block · end of break)

Context. Read from Product brief v1 §5 and §9 and scheduler research §4.7–4.8. Every screen is a 1440×900 display, dimmed ~70%, shown at half size. Sample routine: Hip reset · hips and glutes, four blocks (March in place → Standing hip flexor stretch /side → Wall sit → Box breathing). Movement copy is placeholder in the library's voice; illustrations are out of v1 so none appear.

Shared rules across all five. Movement name readable from 2 m (≥64px). Time remaining always visible: per-block countdown plus overall time left. One primary action per state. Snooze sits closer to hand than Skip; Skip shows today's count and is disabled for the first 3 s (shown enabled here). Done appears from block 3 onward (≥50%). Collapsed state hides the instruction and enlarges the timer; /side state names the side in large type; end state shows the streak count you asked for and a single Back to work button.

Flag. Brief §3 lists streaks as out of v1; your answer asked for a streak count at end of break. Included as asked — easy to swap for the brief's "breaks done today" line.
